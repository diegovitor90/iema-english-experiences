# IEMA English Experiences

Biblioteca digital de experiências pedagógicas em Língua Inglesa — NLI/IEMA.

Site estático responsivo em HTML5, CSS e JavaScript, preparado para publicação no Cloudflare Pages.

### Estrutura
- `index.html`
- `styles.css`
- `app.js`

### Publicação no Cloudflare Pages
Conecte este repositório ao Cloudflare Pages usando a branch `main`.
Como é um site estático, não há etapa de build obrigatória.
